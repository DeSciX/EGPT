# Maxi's bedtime stories

The stories of EGPT, as the author wrote them for people who will not, or cannot, read the
symbols. They are what Maxi's experiences in FRQTL are compressed into: each one teaches a
result that is proved elsewhere in this collection, and each links to where the proof is.
